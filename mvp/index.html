Running it

  1. Open your spreadsheet → Extensions → Apps Script.
  2. Paste the code over anything in Code.gs, then Save.
  3. Pick the function from the dropdown and click Run.
  4. First run only: Google asks you to authorise the script. Read what it asks for before accepting.
